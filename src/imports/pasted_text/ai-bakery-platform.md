Design a modern web application for an AI-powered bakery ordering platform.

The bakery specializes in personalized product recommendations generated by AI. Instead of requiring customers to browse a large menu, the platform intelligently organizes products into personalized categories and recommendations based on customer preferences, ordering history, seasonal trends, and subscriptions.

The application should be designed as a responsive desktop-first web application that can later be implemented in Node.js and ultimately recreated in Python Streamlit.

-------------------------------------------------
BRAND PERSONALITY
-------------------------------------------------

The experience should feel:

- Warm
- Friendly
- Family-oriented
- Easy-going
- Welcoming
- Simple for elderly users
- Delightful but not childish

-------------------------------------------------
AI DIFFERENTIATION
-------------------------------------------------

AI personalization should be the primary feature throughout the application.

The AI should:

- Learn favorite products
- Learn seasonal buying habits
- Recommend treats
- Suggest subscriptions
- Predict reorders
- Generate business forecasts for admins

Visually showcase AI recommendations throughout the user experience without making the interface feel technical.

The experience should feel like a knowledgeable bakery employee making personalized suggestions.

-------------------------------------------------
STREAMLIT COMPATIBILITY
-------------------------------------------------

Design components that can be realistically implemented later in Python Streamlit.

Prefer:

- Cards
- Tabs
- Sidebars
- Forms
- KPI widgets
- Charts
- Chat interfaces

Avoid:

- Complex animations
- Drag-and-drop interactions
- Multi-layer popups
- Advanced front-end interactions

-------------------------------------------------
DELIVERABLE
-------------------------------------------------

Generate high-fidelity screens for:

1. Home Page
2. Full Menu Page
3. Cart Page
4. Profile Page
5. Bakery Concierge Page
6. Subscription Page
7. Admin Analytics Page

Maintain a single cohesive design system and user experience across all pages.
